# When Art Meets Code

AI lets me experiment like never before. The tools are evolving so fast that what was impossible six months ago is now a weekend project.

## The Experiment Loop

My current workflow looks like this:

1. **Sketch** an idea on paper or iPad
2. **Prompt** an AI to generate variations
3. **Code** the best version into a working prototype
4. **Share** and gather feedback
5. **Iterate** — back to step 1

This loop used to take weeks. Now it takes hours.

## What I'm Building

Lately I've been obsessed with:

- **Generative layouts** — CSS Grid + randomness = unique compositions every refresh
- **Physics-based menus** — Why should navigation feel static? Spring animations make everything more playful
- **AI-assisted illustration** — Using Midjourney and Stable Diffusion as starting points, then hand-finishing in Procreate

## The Notebook Philosophy

This site is my notebook. Not everything here is polished. Some experiments are happy accidents. Some are dead ends. That's the point.

> The best way to have good ideas is to have lots of ideas and throw away the bad ones. — Linus Pauling

I'd rather ship ten rough prototypes than one perfect mockup. The feedback from real interactions is worth more than any design review.
